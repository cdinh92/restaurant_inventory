# Restaurant Inventory Management System

A lightweight, intuitive web application built with Flask for tracking and managing restaurant inventory. This tool allows users to monitor stock levels, categorize ingredients, and streamline daily back-of-house operations.

**🚀 Live Demo:** [deandinh97.pythonanywhere.com](http://deandinh97.pythonanywhere.com)

## Features
* **Inventory Tracking:** Easily add, update, or remove ingredients and supplies.
* **Categorization:** Organize items by type (e.g., Produce, Meat, Dry Goods, Beverages) for quicker navigation.
* **Database Management:** Powered by SQLite and SQLAlchemy for reliable data persistence and rapid querying.
* **Cloud Deployment:** Fully hosted and accessible 24/7 via PythonAnywhere.

## Tech Stack
* **Backend:** Python 3, Flask, Flask-SQLAlchemy
* **Frontend:** HTML, CSS, Jinja2 Templates
* **Deployment:** PythonAnywhere, Git
